# SHOQAN — HTML/CSS статикалық нұсқа

Университет жобасының JavaScript-сіз нұсқасы. Беттердің орналасуы, шрифттері, түстері, суреттері және responsive CSS сақталған. Мазмұн дайын HTML файлдарында жазылған.

## Технологиялар

- Қарапайым HTML5 және CSS3; Flexbox, Grid және media query.
- Жергілікті `vendor/bootstrap.min.css` — Bootstrap 5.3.8 стильдері.
- JavaScript файлдары, inline script және JavaScript кітапханалары жоқ.
- Орнату, npm немесе build командасы қажет емес.

## Қалай ашылады

`index.html` файлын браузерде ашыңыз. Суреттер мен CSS жергілікті болғандықтан интернет қажет емес.

Жергілікті сервермен ашу үшін репозиторийдің түбірінде орындаңыз:

```sh
python -m http.server 8000
```

Содан кейін `http://localhost:8000` мекенжайын ашыңыз. Windows-та `py -m http.server 8000` пәрмені де жарайды.

## JavaScript-сіз жұмыс істейтін бөліктер

- Беттер арасындағы navigation, категория сілтемелері және каталогтың 1, 2, 3 беттері.
- Әр тауардың жеке бетіне өту.
- Mobile мәзірін ашу/жабу: checkbox, label және CSS арқылы.
- Product Description, Size guide, Delivery and returns: HTML `details` және `summary` арқылы.
- Register бөлімін ашу/жабу: HTML `details` арқылы.
- Proceed to Checkout сілтемесі checkout бөліміне апарады.

## Статикалық үлгі ретінде қалған бөліктер

Іздеу, күрделі фильтрлер, sorting, тауар опцияларын ауыстыру, сурет көрінісін өзгерту, Add to cart, Wishlist, тауарды өшіру, promo code және себетті автоматты есептеу іске қосылмайды. Басқару элементтері өшірілген және түсіндірме `title` атрибутымен белгіленген.

Себет әрдайым үш үлгі тауарды көрсетеді. Саны мен қорытынды сомасы бекітілген; header ішіндегі `Cart (3)` жазуы да үлгі.

Формалардың HTML құрылымы, label және input элементтері сақталған. Submit батырмалары өшірілген: форма деректері, парольдер, хаттар және тапсырыстар ешқайда жіберілмейді. Аккаунт ашылмайды, төлем алынбайды, localStorage қолданылмайды.

Footer ішіндегі ақпараттық және әлеуметтік батырмалар статикалық үлгі ретінде өшірілген. Кәдімгі navigation сілтемелері жұмыс істейді.

## Кодты түсіндіру

- HTML бет құрылымын және мазмұнын береді.
- CSS орналасуды, түстерді, шрифттерді және экранға бейімделуді басқарады.
- `.menu-checkbox:checked` mobile мәзірінің ашық күйін көрсетеді.
- `<details>` бөлімдерді браузердің өз мүмкіндігімен ашады.
- `<a href="...">` каталог пен өнім беттеріне апарады.
- `disabled` батырманың статикалық үлгі екенін, `readonly` санның өзгермейтінін білдіреді.

Тауар ақпаратын өзгертсеңіз, оның каталогтағы карточкасын, басты беттегі/ұсыныстардағы карточкаларын және жеке өнім бетін де қолмен жаңартыңыз.
